# 菜单骨架库

四套可直接套用的自定义菜单结构。括号里是**汉字数**，用于快速核对是否超限。

**约束复习**：一级菜单最多 3 个、每个 ≤4 汉字；二级菜单每个一级下最多 5 个、每个 ≤8 汉字。

---

## 先决定放几个一级菜单

不要默认摆满 3 个。按**实际有多少东西可挂**来定：

| 现状 | 建议 |
|---|---|
| 文章 < 20 篇，没有合集/产品 | **1–2 个**一级菜单。硬撑三个必然出现空入口 |
| 文章 20–100 篇，有内容合集 | 2–3 个 |
| 有内容 + 有产品/服务/社群 | 3 个，右侧那格给转化 |

**空菜单比没菜单伤害更大。** 读者点进去发现是空的或只有一篇，会直接判定这号没人打理。

---

## 骨架一：个人 IP 号

适合有明确职业身份、靠个人观点和经历吸引读者的号。

```
关于我(3)          写什么(3)          找到我(3)
├ 我是谁(3)        ├ 精选必读(4)      ├ 加我微信(4)
├ 我的作品(4)      ├ 系列专栏(4)      ├ 读者社群(4)
├ 更新说明(4)      ├ 全部合集(4)      ├ 商务合作(4)
└ 媒体报道(4)      └ 年度总结(4)      └ 提问箱(3)
```

**要点**：左侧「关于我」是个人号的信任入口，一定要有一篇正经的自我介绍文章，不是一句话。「我的作品」比「我的经历」有说服力得多——能点开看到实物的东西才叫凭据。

---

## 骨架二：工具 / 方法号

适合输出可复用的方法、工具评测、教程的号。读者来这是为了**拿走东西**。

```
先读这些(4)        拿工具(3)          聊两句(3)
├ 新手入门(4)      ├ 工具清单(4)      ├ 加我微信(4)
├ 高频问题(4)      ├ 模板下载(4)      ├ 读者社群(4)
├ 避坑指南(4)      ├ 实测报告(4)      ├ 投稿纠错(4)
└ 全部文章(4)      └ 资源导航(4)      └ 关于作者(4)
```

**要点**：这类号的中间格是主力，权重最高的资产放这。「先读这些」这个命名比「入门」好——它在替读者做决定，减少选择成本。

---

## 骨架三：商业 / 服务号

适合公司号、产品号，目标是获客和转化。

```
了解我们(4)        产品服务(4)        联系我们(4)
├ 公司介绍(4)      ├ 产品介绍(4)      ├ 在线咨询(4)
├ 客户案例(4)      ├ 价格方案(4)      ├ 预约演示(4)
├ 团队介绍(4)      ├ 帮助文档(4)      ├ 商务合作(4)
└ 行业报告(4)      └ 更新日志(4)      └ 加入我们(4)
```

**要点**：「客户案例」的转化效果通常高于「公司介绍」，如果只能保一个，保案例。服务号可以把「在线咨询」配成客服会话入口。

---

## 骨架四：冷启动新号

文章还很少的时候用这个，**只做两个一级菜单**。

```
必读(2)              找我(2)
├ 这号写什么(5)      ├ 加微信(3)
├ 最好的三篇(5)      └ 关于我(3)
└ 更新计划(4)
```

**要点**：「这号写什么」直接对应新读者的第一个疑问，比任何分类都有用。等文章攒到几十篇、有了明显的主题聚类，再拆成三格。

---

## 菜单命名词库

同一个意思，左边比右边好。核心差别是**动词 vs 名词**、**具体 vs 抽象**。

| ✅ 好 | ❌ 差 | 为什么 |
|---|---|---|
| 看合集 | 内容 | 有动作指令，读者知道点了会发生什么 |
| 找我聊 | 关于 | 「关于」是分类词，不是邀请 |
| 拿工具 | 资源 | 「资源」太空，「拿」是明确的收益承诺 |
| 新手必读 | 入门指南 | 「必读」有筛选感和紧迫感 |
| 加我微信 | 联系方式 | 直接说要干什么 |
| 工具清单 | 推荐 | 「清单」暗示结构化、可扫读 |
| 这号写什么 | 简介 | 用读者心里的原话 |
| 避坑指南 | 注意事项 | 具体、有画面 |

**永远不要用**：`更多`、`其他`、`杂项`、`精彩内容`、`往期回顾`（等于没说，且暴露没想清楚）。

---

## 常见菜单错误

1. **按内容分类建菜单，而不是按读者意图。** 号主脑子里的分类（技术/职场/随笔）和读者想干的事（了解你/拿东西/找你）不是一回事。
2. **三个一级菜单全是内容入口**，没有任何连接方式，读者想找你找不到。
3. **二级菜单写成分类名**（「AI 相关」），点进去还得再翻。二级必须落到一个具体能点开的东西。
4. **挂了链接就不再维护。** 菜单里的合集半年不更新，比不挂更糟。
5. **菜单和简介说的不是一个号。** 简介写"专注 AI Agent"，菜单里三分之二是读书笔记——这是定位没收敛的典型症状。

---

## 落地提示

- 后台路径：**内容与互动 → 自定义菜单**
- 菜单发布后需 **24 小时**左右全量生效，部分用户需重新进入会话才能看到
- 未认证订阅号的菜单**不能跳转外部链接**，只能跳公众号文章或触发回复。这种情况下把外链内容先做成一篇文章，菜单指向那篇文章
- 菜单可设置定时发布和分组可见（服务号能力更全）
