# 六种写法的完整流程与提示词

配合 `../SKILL.md` 使用。每种写法给：适用判断 → 分步流程 → 可直接用的提示词。

---

## ① 访谈式

### 第 1 步：起访谈

```
我想写一篇关于【主题】的公众号文章，但还没想清楚怎么写。

请你扮演一个资深编辑，通过提问帮我把内容挖出来。规则：
1. 一次只问一个问题，等我回答完再问下一个
2. 根据我的回答追问细节，尤其是具体的时间、数字、对话、当时的判断
3. 不要问"你有什么感受""你学到了什么"这类抽象问题
4. 大概问 8-10 轮
5. 问完后帮我整理成文章大纲

现在开始第一个问题。
```

### 第 2 步：追问的方向

好的追问都指向**只有作者知道的信息**：

| 追问类型 | 例句 |
|---|---|
| 具体时刻 | "第一次意识到不对劲是什么时候？当时在做什么？" |
| 试错过程 | "在成功那个办法之前，你还试过什么？为什么没成？" |
| 具体数字 | "大概花了多久？成本是多少？效果差多少？" |
| 反面 | "有没有哪次这个方法失灵了？" |
| 对话 | "当时对方原话是怎么说的？" |
| 判断变化 | "现在回头看，哪个判断是错的？" |

### 第 3 步：整理成稿

```
根据我们上面的对话，帮我整理成一篇公众号文章初稿：
1. 保留我的原话和表达习惯，不要改成书面语
2. 我说得不通顺但生动的地方，保留
3. 补充必要的过渡，但不要加我没说过的观点
4. 需要我补充细节的地方，用【待补：xxx】标出来
```

## ② 大纲式

### 大纲模板（必须带字数配额）

```markdown
## 文章大纲：【标题】

主线判断（一句话）：

### 一、开头（约 200 字）
- 切入方式：【具体场景 / 一个数字 / 一个疑问】
- 要让读者立刻知道：这篇讲什么、和他什么关系

### 二、背景（约 300 字）
- 为什么是现在值得说

### 三、核心论点 1（约 600 字）
- 观点：
- 支撑案例：【具体到可验证】
- 我的判断：

### 四、核心论点 2（约 600 字）
- 观点：
- 支撑案例：
- 我的判断：

### 五、边界 / 反面（约 300 字）
- 什么情况下不成立
- 我自己踩过的坑

### 六、收束（约 300 字）
- 拉高一层的判断
- 一个明确的读者动作
```

### 扩写提示词

```
按这份大纲扩写成公众号文章。要求：
1. 严格按各节字数配额，不要写成每节一样长
2. 每个论点必须有具体案例，没有案例的地方标【待补案例】
3. 段落控制在手机屏 4 行以内
4. 不要用"本质上""换句话说""值得注意的是"
5. 不要编造数据和案例
```

## ③ 续写式

### 先诊断

```
这是我写了一半的稿子，我卡住了。先不要续写。

请你先判断我卡在哪：
A. 大纲没想清楚（不知道下一段该写什么）
B. 缺具体材料（知道要写什么，但没东西可写）
C. 选题本身立不住（越写越觉得没意思）

给出判断和理由。如果是 C，直接告诉我，不要硬续。
```

### 分情况处理

- **A** → 回到 ② 大纲式，把剩下的部分先列出来
- **B** → 列出缺什么材料，作者去补；或转 ① 访谈式，从作者脑子里挖
- **C** → 转 ⑤ 破题式换角度

## ④ 素材整合式

### 第 1 步：压缩

```
下面是我收集的【N】条材料。请逐条压成一句话，标出每条的核心信息。
不要评论，只做压缩。
```

### 第 2 步：找主线

```
基于上面压缩后的 N 条：
1. 这些材料加在一起，最能支撑哪一个判断？给我 3 个候选主线判断
2. 每个候选下面，标出哪几条材料支撑它、哪几条用不上
3. 告诉我哪个候选的材料支撑最扎实
```

### 第 3 步：删

选定主线后：

```
按【选定的主线】重排材料，并明确告诉我：
- 哪几条要删掉（撑不住主线的）
- 删掉后主线是否还成立
```

> **这一步不能省。** 十条材料通常只有五六条真正服务于主线。舍不得删是这种写法最常见的失败。

## ⑤ 破题式

### 角度生成

```
主题是【XXX】。给我 5-8 个可以切入的角度，每个角度：
- 一句话说清是什么角度
- 这个角度需要什么材料才写得实
- 谁会想看

覆盖这几个维度：反直觉、切身经历、横向对比、溯源、代价、特定人群、预测。

最后帮我判断：哪些角度换个作者也能写出一样的（这些划掉），
哪些是只有我这个背景才能写的。
```

### 挑选标准

按顺序问三个问题：

1. **只有你能写吗？** 换个作者写出来一样 → 划掉
2. **材料够吗？** 需要的案例/数据你手上有吗 → 没有就换
3. **你自己有判断吗？** 你对这个角度有明确态度吗 → 没有会写成资讯

## ⑥ 重写式

### 病灶诊断

```
这是我写完但不满意的稿子。先不要改。

请按下面的清单逐项诊断，指出具体在第几段：
1. 开头是否绕（前几段都在铺垫）
2. 有没有"我"（是否只是公开信息复述，缺作者判断）
3. 例子是否具体（有没有"某公司""某用户"这类编造案例）
4. 结论是否悬空（讲完没落到明确判断）
5. 是否太平（每段一样长、一样重要）
6. AI 腔（列出具体句子）

输出病灶清单，按严重程度排序。
```

### 定点手术

```
按病灶清单逐项修改。要求：
- 只改被点名的地方，其余段落一个字不动
- 每处改动后说明改了什么、为什么
- 不要做"整体润色"
```

> **"整体润色"是重写式最大的陷阱。** 它会把文章磨得更顺，同时磨掉所有个人痕迹，结果更像 AI 写的。
