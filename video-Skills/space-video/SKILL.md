# space-video · 视频创作导演

一条视频从想法到成片，中间有七个环节。这个技能是**总调度**：判断你现在在哪一步，把活派给对应的子技能，最后收口做复盘。

## 全流程地图

```text
参考/灵感 ──► ① 选题        space-video-topic     选题·标题·正文·下载参考·逐字稿
            ► ② 脚本        space-video-script    去 AI 味口播稿·精确到秒
            ► ③ 剪辑        space-video-edit      剪口播·删前保后·成片
            ► ④ B-roll      space-video-broll     动效导演·HTML→30s+ MP4
            ► ⑤ 字幕        space-video-subtitle  转写·断句·AI 校对·烧录
            ► ⑥ 配音配乐    space-video-audio     TTS 旁白·找 BGM·压音混音
            ► ⑦ 封面        space-video-cover     封面家族气质
成片 ──────► ⑧ 复盘（本技能收口）
```

## 路由规则

先判断用户手里有什么、想要什么，再决定入口：

| 用户的话 / 手里的东西 | 派给 |
|---|---|
| 「不知道拍什么」「帮我想选题」「这条爆款拆一下」「起标题」 | `space-video-topic` |
| 「稿子写一下」「口播脚本」「这段太 AI 了」「精确到秒的分镜」 | `space-video-script` |
| 「剪一下这条录屏」「口误删掉」「做成片」「时间轴」 | `space-video-edit` |
| 「加点动画」「B-roll」「做个 motion 开场」「HTML 转视频」 | `space-video-broll`（代码渲染，确定性、免费） |
| 「文章转图解视频」「手绘白板动图」「Seedance/libtv 出 B-roll」 | `space-video-broll-sketch`（调视频模型生成） |
| 「上字幕」「转写」「srt」「烧录字幕」 | `space-video-subtitle` |
| 「配音」「配乐」「加 BGM」「找音乐」「TTS 旁白」「混音」 | `space-video-audio` |
| 「做封面」「缩略图」「首图」 | `space-video-cover` |
| 「从头帮我做一条」 | 从①开始，逐环节走 |

**不确定就先问一句**：这条视频是口播/录屏/混剪？发哪个平台（竖屏 3:4 / 横屏 16:9）？有没有参考？

## 一条龙时的交接约定

各环节用文件交接，不要把上一步的结果只留在对话里：

```text
项目目录/
├── 00_参考/        下载的参考视频、逐字稿
├── 01_选题/        选题.md、标题候选.md、正文.md
├── 02_脚本/        script.md（精确到秒）
├── 03_剪辑/        source_cut.mp4、cutlist.json
├── 04_broll/       *.mp4 B-roll 片段
├── 05_字幕/        subtitles.srt
└── 06_封面/        cover.png
```

每步产出落盘后，再进下一步。子技能之间不直接互相调用，统一由本技能编排。

## ⑦ 复盘（成片后收口）

成片发布后，帮用户沉淀：

1. **数据**：完播率、点赞/评论比、涨粉，哪个环节可能是瓶颈
2. **钩子回看**：前 3 秒留没留住人
3. **可复用资产**：这条里哪个 B-roll / 封面模板 / 选题公式下次能复用
4. 追加一条到用户的视频复盘记录（若有）

## 核心原则

- **单一职责**：本技能只做调度和复盘，不亲自剪、不亲自写；具体活交子技能
- **落盘交接**：每步产出写成文件，可追溯、可回退
- **平台先行**：动手前先定比例和平台，避免竖屏横屏返工
