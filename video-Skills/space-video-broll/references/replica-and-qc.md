# 参考片复刻 + 成片 QC

当用户给一条**参考视频**要「复刻同款动效」时，走这套。目标是**原创改编**：保留视觉语法、布局逻辑、节奏和交互语言，替换掉源片的文案、素材、口播、画面。

## 版权边界（先守住）

- 只处理用户有权使用的公开链接或本地文件。
- 不绕过私密账号、DRM、付费墙、已删除内容。
- 源视频/截图/逐字稿放私有工作目录，**不打包进成片或 Skill**。
- 复刻的是运动结构、布局、节奏、交互语言；文案和素材要原创或通用。

## 复刻流程

1. **锁定研究区间**：起止时间、要复刻的效果、成片比例、是预览还是成品。画布/帧率默认跟参考。
2. **获取并核验参考**：`yt-dlp` 下载 → `ffprobe` 核验（可播放、时长非零、已知宽高帧率）。HTTP 200 不等于拿到了。
3. **生成视觉证据**：对区间抽联络图/关键帧。记五层证据：
   - 视觉 token：背景/描边/配色/字体/阴影/纹理
   - 几何：安全边距/锚点/卡片尺寸/连线走向/层级
   - 运动基元：pop / slide / path-draw / swap / push / blur / zoom
   - 顺序：谁先入、谁等待、谁替换了前一个状态
   - 时序：入场时长 / 停留 / 重叠 / 转场时长 / 收尾定格
   - 写 `frame.md`(视觉契约) 和 `STORYBOARD.md`(带时间戳的顺序) 再动画。
4. **先搭布局再做动画**：每个场景先构到最显眼状态，确认卡片/标签/连线不动时也放得下；再按阅读顺序动画：框→区块标签→第一焦点→下一端点→端点间连线→支撑卡片逐个。

## 成片 QC（交付前）

用 `ffprobe` 核验成片，别只信渲染没报错：

- [ ] 时长、分辨率、帧率符合预期
- [ ] 抽 5–8 个关键帧目检：无穿帮、无空帧、文字不出血、安全区 OK
- [ ] Anti-PPT 复查：≥80% beat 有真实状态变化
- [ ] 无 emoji；图标为 SVG/几何/文字
- [ ] 首帧/尾帧干净（可做封面/可接下一镜）

> 不承诺像素级/帧级对齐。要精确对齐参考，先过 QC 门再谈。
