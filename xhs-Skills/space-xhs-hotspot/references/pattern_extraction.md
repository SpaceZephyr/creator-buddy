# 爆款共性提取方法论

移植自 `creator-buddy/skills/baokuan-article-analysis`（公众号爆文分析）的分析骨架，按小红书的字段和内容生态改写。

SKILL.md 第 3 步（五个切口）回答的是「这个赛道现在是什么样」；本文回答的是**「这批爆款为什么爆，其中哪些我能抄，哪些抄不了」**。样本 ≥ 8 条时执行，< 8 条只做定性描述并说明样本不足。

---

## 一、给每条笔记打两个标签

对 top 20 逐条打标，不要跳过——共性是数出来的，不是感觉出来的。

### 标签 A：内容形态（决定你要怎么写）

| 形态 | 识别信号（标题/正文摘要里出现） | 可复用性 |
|---|---|---|
| 清单盘点 | 数字 + 「个/款/条」、合集、盘点、必看 | 高，人人能写 |
| 教程步骤 | 教程、怎么、步骤、保姆级、手把手、从 0 到 1 | 高，但要真会 |
| 测评对比 | 测评、实测、对比、vs、哪个好、拔草 | 中，需成本投入 |
| 个人经历 | 我、第 N 天、复盘、记录、从 X 到 Y | 中，依赖真实经历 |
| 避雷吐槽 | 避雷、别买、翻车、后悔、劝退 | 高，但有合规风险 |
| 数据结论 | 数字结论、涨了多少、花了多少钱、真相 | 低，要有独家数据 |
| 资源合集 | 网盘、模板、素材、免费、整理好了 | 高，注意版权 |
| 身份背书 | 医生、HR、律师、X 年经验、在职 | 低，抄不了身份 |

### 标签 B：爆款机制（决定它为什么被推）

一条笔记可以命中多条，取最强的 1~2 条：

| 机制 | 表现 | 迁移到自己选题的方式 |
|---|---|---|
| 新鲜感 | 新产品、新玩法、新政策、新说法 | 标题直接说「新在哪」，别埋 |
| 结果感 | 可量化结果：瘦了 X 斤、省了 X 元、涨粉 X | 开头三行内给数字锚点 |
| 场景感 | 锁死一个具体场景（出租屋/通勤/宿舍） | 少讲概念，多讲「什么时候用得上」 |
| 身份感 | 明确圈定人群（打工人/学生党/宝妈） | 标题带人群标签，评论区自动聚人 |
| 情绪感 | 委屈、爽、破防、共鸣式吐槽 | 用读者的原话当标题 |
| 反差感 | 「没想到」「原来」「越 X 越 Y」 | 先立一个默认认知再推翻 |
| 收藏动机 | 模板、清单、参数、可保存的信息密度 | 内容里必须有一块能截图带走 |
| 争议感 | 立场鲜明、二选一、劝退 | 评论区拉动二次曝光，但要控合规 |

## 二、数出共性（输出的是分布，不是形容词）

把标签汇总成三行数字：

```
形态：清单 9/20 ｜ 测评 5/20 ｜ 经历 4/20 ｜ 避雷 2/20
机制：收藏动机 12/20 ｜ 身份感 9/20 ｜ 结果感 7/20 ｜ 反差感 3/20
标题高频词：通勤、平价、5 个、打工人、显瘦、一整年
```

标题高频词的取法：把 top 20 标题分词，去掉「的了和在是」这类停用词和赛道词本身，按出现次数降序取前 10~14 个。这批词就是**该赛道当前的搜索入口**，直接交给 `space-xhs-title` 当词库。

**判定阈值**：某个形态或机制占比 ≥ 40% 才叫「共性」；20%~40% 叫「次主流，可做差异化」；< 20% 且只有 1~2 条支撑的，说成「个例」，不要包装成趋势。

---

## 三、拆成三张清单（交付重点）

### 清单 1：可复用（我明天就能照做）

条件：不依赖特殊身份、不依赖独家数据、不依赖高成本拍摄。
写法：`共性描述 → 对标笔记（带链接）→ 换到用户的赛道上该怎么落地`。

### 清单 2：不可复用（看看就好，别硬追）

典型三类，必须明确点出来是哪一类：
- **身份壁垒**：三甲医生、大厂 HR、十年从业——你没有这个身份，同样内容说服力归零。
- **资源壁垒**：独家数据、样品堆、高成本场地、明星资源。
- **账号壁垒**：50 万粉大号的「日常碎片」也能爆，那是账号权重不是内容质量，新号照抄必沉。

### 清单 3：空位（榜上没有但值得试）

从形态表里找**占比为 0 或 < 10%、且用户有能力做**的形态。这是差异化机会，但必须同时写明风险：可能是没人做，也可能是平台在这个赛道不给这个形态流量——两种解释都要摆出来，让用户自己判断。

## 四、选题公式化

把共性折成 3~5 条可套用的公式，交给下游 skill：

```
公式：<高频机制> + <主流形态> + <人群/场景词>
例：  收藏动机 + 清单 + 打工人  →「打工人通勤的 5 件平价单品，闭眼买」
      反差感 + 测评 + 学生党    →「学生党别再买贵的了，这 3 款平替我实测更好用」
```

公式要从**本轮数据**里长出来，不要套模板库。每条公式必须能指回至少一条对标笔记。

---

## 五、红线（沿用 SKILL.md 的口径）

- 占比是观察，不是因果。写「这个赛道读者对 X 响应更好」，不写「用 X 就能爆」。
- 样本 < 8 条不做占比，只做定性，并写明「样本 N 条，结论仅供参考」。
- 不可复用清单不能省——只给「可以抄的」等于把用户往坑里带。
- 所有共性都要挂对标笔记链接，链接原样保留 `xsec_token`。
