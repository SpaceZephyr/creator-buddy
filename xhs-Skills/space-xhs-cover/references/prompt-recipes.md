# 封面提示词配方

## 标准提示词骨架

每次调用前根据用户内容填满方括号：

```text
Use case: ads-marketing

制作一张 3:4 竖版小红书封面，最终用于 1080×1440 像素。

主题：[一句话主题]
目标读者：[具体人群]
希望传达：[核心价值]

封面文字必须逐字准确：
主标题第一行：“[文字]”
主标题第二行：“[文字]”
副标题：“[文字或无]”
除以上文字外，不要生成任何其他文字、字母、数字、水印、签名或标识。

输入图角色：
- 图 1：[主体图/背景图/风格参考]，[使用方式]
- 图 2：[角色]，[使用方式]

构图：[构图名称与主体占比]
风格：[风格名称与视觉语言]
字体：[字形气质]
配色：[底色、文字色、强调色]
强调词：[需要突出显示的词]
装饰：[最多 3 组]

主标题是第一视觉，主体是第二视觉，副标题是第三视觉。
重要内容距四边保留约 10% 安全边距，画面保留约 20% 留白。
移动端缩略图下仍然一眼可读。
标题不能遮挡人物脸部、双手、产品名称或关键结构。
中文笔画完整、无乱码、无错字、无重复字。

避免：[与当前风格冲突的元素]
```

## 无输入图片

省略“输入图角色”，补充：

```text
从零生成主体：[主体外观、动作、服装、视角和情绪]。
背景：[场景、光线、景深和留白位置]。
```

## 人物主体

```text
图 1 是人物主体图。严格保留人物身份、脸部特征、发型、肤色、服装和整体姿势。
可做自然光线、轮廓分离和背景融合，不改变五官，不进行过度磨皮，不新增首饰或文字。
人物放在画面[左/右/中央]，约占画面[比例]，标题区位于[位置]。
```

## 产品主体

```text
图 1 是产品主体图。严格保留产品外形、颜色、包装比例、按钮、接口和已有标识位置。
产品边缘清楚，材质真实，不新增虚构功能或包装文字。
```

## 多张背景

不要含糊地说“参考这些图”。逐张说明：

```text
图 2 只提供室内空间与光线。
图 3 只提供桌面材质与配色。
图 4 只提供远处城市轮廓，不复制其中的文字和标识。
把这些元素融合成一个统一、可信的背景，不做图片拼盘。
```

## 参考风格

```text
图 2 只作为风格参考：提取其留白比例、色彩关系、标题层级和纸张质感。
不要复制图中的人物、标识、文字、插画、独特图形或完整布局。
```

## 三张变体

标题和主体保持一致，分别使用：

1. 强标题：标题占比最大，主体辅助
2. 强主体：人物或产品占比最大，标题进入留白区
3. 强氛围：场景与色彩更突出，但标题仍清晰

每个变体分别调用一次 `image_gen`。

## 六张变体

按以下维度形成真正差异：

1. 左字右人，浅色专业
2. 背景大字，黑白强对比
3. 中央主体，品牌海报感
4. 清单卡片，教程感
5. 分屏构图，结果感
6. 拼贴构图，故事感

如果某种构图与内容不匹配，替换为风格库中更合适的构图，仍要保证六张不只是换色。

## 定向修正模板

### 修文字

```text
只修正封面文字：
把“[错误文字]”准确替换为“[正确文字]”。
字数、换行和位置保持一致。
人物、背景、构图、颜色、光线和其他元素全部保持不变。
不要新增任何文字。
```

### 修遮挡

```text
只调整标题区域：把标题整体向[方向]移动约[比例]，完整露出人物的脸和手。
标题内容、字体、颜色、人物身份、姿势和背景全部保持不变。
```

### 修留白

```text
保持标题、主体和风格不变，减少无关装饰，扩大[位置]的留白。
四周安全边距至少约 10%，装饰簇不超过 3 组。
```

## 无字底图回退

当中文文字连续两次仍不准确时：

```text
生成同一张封面的无字底图。
删除所有文字、字母、数字、水印和标识。
在[指定位置]保留干净、对比足够的标题区域，面积约占画面[比例]。
人物、产品、背景、配色、光线和构图保持不变。
```

随后用可编辑 HTML/CSS 叠加标题，不继续赌文字生成。
