# 小红书爆款标题生成器

追求"手指划过的 0.5 秒被拽停"，但**绝不牺牲标题与正文的一致性，也绝不踩平台违规词**。不是给一个标题，是给一桌菜——多方法、多用途、可筛选、可 A/B。

**核心原则**：小红书标题同时干两件事——
1. **在信息流里被划过时抓住人**（情绪 + 人群 + 缺口）；
2. **在搜索框里被搜到**（关键词命中）。
只做到第一件的标题活三天，两件都做到的标题吃半年长尾流量。

---

## 平台事实校准（先记住这些，别用公众号的直觉写小红书）

生成时用这些事实校准。下面标 **【平台规则】** 的是平台的硬性机制，标 **【经验】** 的是创作侧的普遍观察，不是官方公布的统计数据——按经验值使用，别当数据引用：

- 【平台规则】**硬上限 20 个字符**（emoji 也占字符位）。**最佳区间 13~18 字**，正文封面上还会二次露出关键词，标题别贪长。超过 20 字会被平台截断，句尾信息直接丢失。
- 【平台规则】**小红书是搜索型社区**，笔记除信息流分发外还持续吃搜索与"搜索后推荐"的流量。标题里没有用户会打进搜索框的词，等于放弃长尾。**这一点的权重远高于公众号。**
- 【经验】**一个押准的搜索词，胜过三个堆上去的关键词。** 20 字的预算里，与其塞满品类词，不如把一个主搜索词写完整（"油皮粉底液"优于"美妆 好物 粉底 推荐"）。关键词堆叠还会被判为营销行为。
- 【经验】**强第一人称、强口语**。"我""姐妹们""谁懂啊""救命""真的会谢"——书面腔在小红书是劝退信号。
- 【经验】**emoji 是标配不是克制项**（与公众号完全相反）。1~2 个，放句首吸睛或句尾定情绪。**别超过 3 个**，堆满 emoji 会被识别为营销号。
- 【经验】**人群标签前置**："学生党""i人""小个子""新手妈妈""油皮""通勤党""预算党"。读者在半秒内确认"说的是我"。
- 【经验】**高收藏结构吃香**：数字清单 + "建议收藏""码住""照抄就行"。收藏是小红书最强的正反馈信号之一。
- 【经验】**负向选题表现极强**："踩雷""别买""劝退""后悔没早知道""这几个千万别碰"。避雷类的点击率长期高于种草类。
- 【经验】**符号习惯**：`｜`（竖线）做分区最常见（`学生党｜宿舍好物`），其次是感叹号、问号、括号补语。**冒号不如公众号常用**。

**不应误读**：加了"救命"和 emoji 不会自动爆。笔记数据由封面、账号标签、发布时段、正文留人共同决定，标题只优化"点进来"和"搜得到"这两段。

## 15 种小红书标题方法（附范例 + 公式 + 红线）

生成时**至少覆盖 6 种不同方法**，不要 10 个标题一个套路。每条优先用一个主方法，最多叠加一个辅助方法。

### 1. 人群标签前置
把目标人群的自称词放在最前面，让对的人半秒认领，也让平台把你推给对的标签池。
- 范例：`学生党｜300块搞定一整个宿舍✨` / `i人友好的搭子型运动💃`
- 公式：`[人群词] ｜ [他们的具体处境] + [结果]`
- 红线：人群词必须是正文真正服务的对象，不能为了流量硬贴（贴错人群会拉低账号标签精度，比没标签更糟）。

### 2. 搜索词卡位
用用户真的会打进搜索框的词做标题主干——通常是"品类 + 场景 + 修饰"的组合，不是漂亮的文学表达。
- 范例：`上海周末citywalk路线｜不累版🚶` / `油皮夏天不脱妆的粉底液`
- 公式：`[核心搜索词] + [限定条件] + [差异化后缀]`
- 红线：不硬塞与内容无关的热词。堆无关关键词是平台明确打击的行为，会被限流。

### 3. 数字清单 + 收藏指令
给出可数的量 + 一个明确的收藏动作词，直接激活收藏行为。
- 范例：`7个提升效率的神器｜建议码住📌` / `毕业论文5个救命工具，别谢我`
- 公式：`[数字] + [品类/方法] + [建议收藏/码住/直接抄]`
- 红线：数字必须与正文条目数一致。写 7 个正文只有 4 个 = 骗收藏，掉评论区差评。

### 4. 避雷劝退（负向）
说"别做什么"，比说"做什么"更有点击。小红书最稳的一类。
- 范例：`这3款别买了，真的踩雷😭` / `装修千万别学我这样铺地板`
- 公式：`[品类/行为] + 别买/别踩/千万别 + [代价]` 或 `我踩过的[N]个坑`
- 红线：**指名道姓的负面评价必须是自己的真实体验，且限定为主观感受**，不能捏造产品缺陷、不能影射品牌造假（涉及法律风险）。没真用过就写品类通用坑，不点名。

### 5. 后悔体 / 相见恨晚
用"早知道就好了"的遗憾情绪，暗示这是稀缺信息。
- 范例：`后悔没早点知道这个方法😭` / `这个功能我居然现在才发现`
- 公式：`后悔/居然/竟然 + 没早知道 + [具体的事]`
- 红线：内容必须真的有信息增量。人尽皆知的常识配"后悔没早知道"= 标题党。

### 6. 情绪惊叹（救命体）
把读者看到内容时的第一反应直接写成标题。
- 范例：`救命这也太好用了吧😭` / `谁懂啊，我终于把它搞定了`
- 公式：`救命/天呐/谁懂啊/真的会谢 + [对象] + [强反应]`
- 红线：**单独用会很空，必须配一个具体对象或结果**。纯情绪词没有搜索价值，需与方法 2 叠加。

### 7. 亲测对比（前后反差）
用可见的变化建立可信度，是种草类最硬的钩子。
- 范例：`坚持3个月，皮肤肉眼可见变好` / `同一间房，我只换了这2样`
- 公式：`[时长/动作] 后，[可观测的变化]` 或 `[变量A] vs [变量B]`
- 红线：**没真实做过不得写"亲测""坚持了 X 个月""实测"**。效果类描述要写自己的感受，不写疗效（见合规红线）。

### 8. 保姆级教程 / 新手向
承诺零门槛可复制，直接对准"我也想会"的人群。
- 范例：`新手也能学会的剪辑｜保姆级🎬` / `零基础做PPT，3步就够`
- 公式：`零基础/新手/小白 + [目标] + 保姆级/N步搞定`
- 红线：正文必须真的是 step-by-step，且步数与标题一致。给不出可操作步骤就别用"保姆级"。

### 9. 反常识纠错
推翻一个被默认的做法，制造"我是不是一直做错了"的不安。
- 范例：`原来这一步一直都做反了😳` / `别再这样洗了，越洗越糟`
- 公式：`原来/其实 + [常见做法] + 是错的` 或 `别再 [常见动作] 了`
- 红线：反的必须是真的错误做法，要有正文依据。不为了反转而反转。

### 10. 悬念缺口
只说"发生了什么"或"有个东西很好"，不说是什么。
- 范例：`打工人必备的这个App，我藏不住了` / `我妈的这招，全家都服了`
- 公式：`[人群] + [强评价] + 但不说明对象`
- 红线：**小红书慎用纯悬念**——藏掉全部关键词会同时损失搜索流量。悬念标题必须至少保留 1 个可搜索词。

### 11. 场景具体化
把一个生活画面写进标题，读者自动代入。
- 范例：`加班到10点还能吃口热的🍜` / `出租屋厨房，也能做出这一桌`
- 公式：`[具体时间/地点/困境] + [依然做到了什么]`
- 红线：场景是真实生活，不编造人设经历。

### 12. 平替 / 省钱 / 性价比
明确的金钱利益点，小红书最高频的消费动机之一。
- 范例：`平价平替｜30块用出300块的效果` / `预算500，我全买齐了`
- 公式：`[预算数字] + 搞定/买齐 + [目标]` 或 `[贵价对象] 的平替`
- 红线：**价格必须真实且注明时间/渠道口径**；"平替"是主观相似度判断，不能宣称与大牌"效果相同""成分一致"（易触碰虚假宣传）。

### 13. 时间承诺
用一个具体的时间尺度让结果显得可达成。
- 范例：`7天，我把卧室彻底改造了` / `每天10分钟，一个月的变化`
- 公式：`[时长] + [投入] + [结果]`
- 红线：时长与结果必须来自真实经历，不承诺他人复现同样效果。

### 14. 求助 / 提问互动
把标题写成一句真诚的提问，直接换评论区。
- 范例：`这样穿显高吗？在线等👀` / `姐妹们，这两个选哪个？`
- 公式：`[具体选择困境] + 在线等/求推荐/怎么选`
- 红线：正文要真的接得住讨论，别问完自己给答案。这类标题**互动高但搜索价值低**，不宜作为账号主力。

### 15. 节点 / 季节 / 热点绑定
挂上当下人人都在搜的时间节点。
- 范例：`换季必备清单｜这5件先囤` / `国庆3天，穷游也能玩爽`
- 公式：`[节点词] + [人群/预算] + [具体产出]`
- 变体（社会证明）：`第一批 [做了某事] 的人，已经 [结果了]`——用"别人已经开始了"制造从众压力，节点类内容尤其好用。
- 红线：热点要与内容真实相关；社会事件、灾难、公共安全类热点一律不蹭。"第一批"必须是真实存在的群体现象，不是杜撰的人群。

### 附加：慎用型（张力强，也最容易违规或透支信任）
- **绝对化拔高**：`最好用的XX`——**小红书对绝对化用语审核严于公众号**，"最""第一""顶级""销量冠军"极易触发限流，非必要不用。
- **焦虑制造**：`不看这条你会后悔一辈子`——过度恐吓会被判为标题党。
- **数据炫耀**：`月入5万的副业`——收入类承诺是重点审核对象，需谨慎表述为个人经历。

## 10 个小红书增强器

生成候选后逐条"加辣"，可叠加：

1. **人群词前置**：句首插入"学生党""i人""小个子""新手妈妈"。
2. **竖线分区**：`场景｜结果`，一眼两段信息，小红书最典型的版式感。
3. **emoji 定调**：1~2 个，句尾定情绪（😭 崩溃 / ✨ 好物 / 📌 收藏 / 🔥 热度 / 👀 好奇）。**别超 3 个**。
4. **口语化换词**："提升效率"→"不用加班了"；"具有性价比"→"便宜到离谱"。
5. **搜索词补位**：检查标题里有没有一个用户真会搜的名词，没有就换掉一个形容词补进去。
6. **收藏钩子加尾**：句尾加"建议收藏""码住""照抄就行"（仅当内容真的可复用时）。
7. **具体数字替换模糊词**："很多"→"7个"；"便宜"→"30块"。
8. **第一人称化**：把陈述句改成"我"的经历——"这样做更好" → "我这样做之后…"。
9. **原话加引号**：把用户会脱口而出的那句抱怨/惊叹原样搬进标题并加引号——`"这也太难删了吧！"`。引号自带"有人在说话"的现场感，比转述更抓人。**原话必须是真实听过/正文里出现过的说法，不编造用户证言。**
10. **身份反差**：让"不该说这话的人"来说——`我妈看完直接下单了` / `理发师朋友劝我别买`。反差身份要真实存在于正文，不虚构人设。

**增强器不叠加事实**：加辣改的是表达，不是往标题里加正文没有的东西。

## 工作流程

### 第 0 步：判断输入类型

- **A. 给主题起标题**（用户给主题/草稿/产品）→ 走第 1 步。
- **B. 给现有标题做优化**（用户贴了一条已有标题）→ 跳到本文末尾「改写现有标题」，做完诊断后再回到第 2~4 步。

### 第 1 步：建内容简报

读完内容，先抽出这些（缺的标出来，**不虚构**）：

- **目标人群**：他们怎么自称？（这决定人群标签词）
- **搜索意图**：这个人群会在搜索框打什么？列 3~5 个候选搜索词。
- **核心对象**：具体的产品/地点/方法/工具是什么？
- **可兑现的结果**：读者能得到/避免什么，正文能证明到什么程度？
- **证据资产**：真实数字、价格、时长、前后对比、亲身经历。
- **情绪基调**：崩溃 / 惊喜 / 心疼 / 解气 / 治愈 / 好奇。
- **收藏理由**：这条为什么值得存下来？（存不下来就别用收藏型方法）
- **时效等级**：即时热点 / 节点季节性 / 常青长尾。**常青内容要把搜索词权重拉满**（它靠半年的搜索吃饭）；节点内容才值得押节点词，节点一过就失效。
- **事实边界**：正文**没有**证明的结论、效果、价格、排名——不许进标题。
- **合规风险点**：内容里是否涉及医疗、功效、投资收益、绝对化表述。

内容里如果有**真实价格、真实时长、用户原话吐槽、前后对比照片说明**，一定先抓出来——它们是小红书标题最好的原材料，比任何形容词都值钱。

信息不足就先出保守版，并说明缺什么限制了标题强度——**不要靠编造补强度**。

### 第 2 步：按内容类型路由方法

| 内容类型 | 优先方法 | 不宜优先 |
|---|---|---|
| 好物种草、测评 | 亲测对比、平替省钱、人群标签、避雷劝退 | 纯悬念、求助 |
| 干货教程、工具 | 数字清单+收藏、保姆级、搜索词卡位 | 情绪惊叹单用 |
| 避雷拔草、辟谣 | 避雷劝退、反常识纠错、后悔体 | 绝对化拔高 |
| 探店、旅行、路线 | 搜索词卡位（地名必进）、节点季节、场景具体化 | 悬念缺口 |
| 穿搭、美妆 | 人群标签（身材/肤质）、亲测对比、求助互动 | 数据炫耀 |
| 个人成长、Vlog | 时间承诺、场景具体化、后悔体、第一人称反差 | 数字清单 |
| 情绪共鸣、吐槽 | 情绪惊叹、场景具体化、求助互动 | 保姆级 |
| 知识科普、答疑解惑 | 反常识纠错、搜索词卡位、数字清单+收藏 | 情绪惊叹单用、悬念 |
| 家居、母婴、装修 | 避雷劝退、亲测对比、平替省钱、场景具体化 | 绝对化拔高 |
| **商单、品牌合作** | 人群标签、场景具体化、搜索词卡位（品牌/品类词必进） | 避雷劝退、绝对化、功效断言、数据炫耀 |
| **素材弱、没硬料** | 搜索词卡位、场景具体化、求助互动 | 亲测、数字、平替 |

### 第 3 步：多方法批量生成

默认 **12 个候选，至少 6 种方法**；用户说"多一些"扩到 20。尽量覆盖：搜索型、清单型、避雷型、体验型、情绪型、场景型各 1~3 个。

**只在正文支持时用对应方法**：没真用过不写"亲测"，没有 N 条不写数字，没有价格凭据不写具体金额。

**逐条自检字符数**，超过 20 字的直接砍到 18 字以内再进入评分。

### 第 4 步：评分、去重、合规校验

按下面的评分表逐维打分，然后：删掉超字数的、删掉正文兑现不了的、删掉只改一两个词的同质标题、删掉触碰违规词的、标记中高风险的。

## 评分规则（百分制，逐维打分，别凭感觉报总分）

| 维度 | 分值 | 判断 |
|---|---:|---|
| 内容兑现度 | 20 | 正文能否兑现标题承诺？ |
| **搜索词覆盖** | 15 | 是否含至少 1 个用户真会搜的名词？是否是主流搜法而非生僻表达？ |
| **人群指向性** | 15 | 目标人群能否在半秒内确认"说的是我"？ |
| 情绪与钩子 | 12 | 有没有一个让人停手指的情绪点或缺口？ |
| **收藏动机** | 10 | 读者有没有理由把它存下来（清单/教程/避雷/可复用）？ |
| 具体性 | 10 | 有明确对象/数字/场景，而非空泛形容？ |
| 字数与节奏 | 8 | ≤20 字符、重点前置、一遍读懂、无赘词？ |
| 口语与平台感 | 5 | 像小红书用户说的话，不是公众号腔？ |
| 独特性 | 5 | 区别于同主题满屏都是的写法？ |

**强制扣分 / 直接淘汰**：
- 超过 20 字符 → **直接淘汰**（或先砍到合规再评）
- 标题核心承诺正文无法兑现 → **直接淘汰**
- 捏造数字、价格、亲测经历、条目数、排名 → **直接淘汰**
- 触碰下方"平台违规红线"任一条 → **直接淘汰**
- 把推测/个例写成已发生的普遍事实 → −15
- 标题里一个可搜索名词都没有 → −15
- 夸大因果或把"我用着好"扩大成"所有人都适用"（"人人都该买""闭眼入不踩雷"）→ −12
- 人群词与正文实际服务对象不符（硬贴标签） → −12
- 把主观感受写成客观效果 → −12
- 无依据的"最/第一/唯一/永久" → −12
- 纯情绪堆砌、无具体对象 → −10
- 数字与正文条目数不一致 → −10
- 悬念过度、把对象和关键词全藏掉（既没人搜得到，也不知道在说什么）→ −8
- emoji 超过 3 个或与语义无关 → −5
- 书面腔、公众号味重 → −5

**风险分级**：
- **低**：事实都在正文、无功效/绝对化表述、人群词准确。
- **中**：用了强情绪词、点名了具体品牌、含价格或时长承诺——须标出要核验的词。
- **高**：涉及功效/医疗/收益承诺、绝对化用语、未经证实的负面指控、靠误解才成立。
  **高风险不得做综合首选**，且必须在输出里写清"为什么高风险 + 安全改法"。

## 平台违规红线（小红书比公众号严格得多，务必逐条过）

以下在小红书是**限流/违规重灾区**，比"标题党"后果严重：

1. **医疗与功效**：禁用"治疗""祛痘""祛斑""美白""瘦身""排毒""抗炎""修复屏障""生发"等疗效/功效断言。
   → 安全改法：写主观感受与可观测现象——"我用完的感受""上脸没有闷痘"。
2. **绝对化用语**：禁用"最好""第一""顶级""销量冠军""百分百""永久""国家级"。
   → 安全改法：限定为个人视角——"我用过最顺手的"（仍需谨慎）或直接换成具体差异点。
3. **收益与投资承诺**：禁用"稳赚""包过""月入 X 万"作为承诺式表述。
   → 安全改法：写成个人经历且不承诺可复制。
4. **虚假与夸大**：不捏造前后对比、不编造亲测、不虚标价格、不伪造条目数。
5. **点名贬损**：不对具体品牌做未经证实的负面指控（如宣称造假、有毒、致病）。主观体验须清晰标注为个人感受。
6. **诱导与导流**：标题不出现"加V""私信领取""进群""关注领资料"等导流指令。
7. **敏感与擦边**：软色情擦边、性别对立煽动、地域攻击、社会灾难蹭热点，一律不做。
8. **未成年人相关**：不做涉及未成年人的容貌、身材评价类标题。

**判断口诀**：这句话如果被截图发到平台举报入口，能不能站得住？站不住就改。

## 输出格式

### ① 内容标题简报
4~6 行：目标人群及其自称词、候选搜索词（3~5 个）、核心对象、最大爆点、可用证据、事实与合规边界。

### ② 候选标题矩阵

| # | 候选标题 | 字符数 | 方法 | 钩子/搜索词 | 评分 | 风险 |
|---|---|---:|---|---|---:|---|

- 方法标签用上面 15 种的标准名；组合写成「主方法 + 辅方法」。
- "钩子/搜索词"一栏必须标出这条标题押的搜索词是哪个。
- 中高风险必须写原因。

### ③ Top 5 推荐（按用途分角色，不是按分数机械排）

1. **综合首选**：点击、搜索、可信度最平衡
2. **搜索版**：关键词最完整，吃长尾流量，适合做常青笔记
3. **爆点版**：情绪/反差/避雷最强，适合冲首发流量
4. **收藏版**：清单感最强，收藏率导向
5. **稳健版**：零合规风险，适合品牌合作、商单、专业号

每个一句话说明为什么适合，并点出主要得分项和实际扣分项。**若 5 个来自同一方法，用略低分但方法不同的候选替换。**

### ④ A/B 测试建议
给 2~3 组，每组**只改一个变量**，写清假设：
- 有 emoji vs 无 emoji
- 人群词前置 vs 结果前置
- 数字清单 vs 单点故事
- 正向种草 vs 负向避雷
- 陈述句 vs 求助问句

**每组必须写清看哪个指标**，否则测了也读不出结论：
- 情绪/emoji/反差类变量 → 看**点击率**（首日曝光转点击）
- 搜索词/人群词类变量 → 看**搜索进入占比与 7 天后的长尾曝光**，首日数据不作数
- 清单/收藏钩子类变量 → 看**收藏率**
同一账号两条笔记的发布时段、封面风格要尽量一致，否则变量不止一个。

### ⑤ 配套提示（可选，一行带过）
标题里的核心搜索词是否也进了正文首句和话题标签？三处一致，搜索权重才起得来。

## 改写现有标题

用户贴了原标题时，按这个顺序做：

1. **诊断**（逐项打勾/打叉）：字符数是否超限 / 有没有可搜索的名词 / 有没有人群指向 / 有没有情绪或缺口 / 有没有收藏理由 / 是否有公众号腔 / 是否触碰违规词。
2. **保留资产**：明确指出原标题里已经有效的部分（一个好搜索词、一个真实数字、一个准确人群词），改写时**不要把它改掉**。
3. **产出至少 12 个改写版**，覆盖 4 种以上方法，其中：
   - 3 个 **稳健优化**（只修字数、口语、搜索词，风格不变）
   - 6 个 **换方法重写**（换成不同的标题方法）
   - 3 个 **激进测试**（情绪/反差拉满，风险自标）
4. **明确标注**每条属于哪一类，并说明"改动了什么变量"。

**不要把"更夸张"当成唯一优化手段。** 小红书上很多标题的问题不是不够刺激，而是没有一个词能被搜到。

## 红线（总纲）

- 不捏造数字、价格、条目数、亲测经历、排名、独家。**可以留缺口，不能撒谎。**
- 不写功效断言、绝对化用语、收益承诺——这在小红书是限流级别的问题，不只是可信度问题。
- 不硬贴人群标签、不堆无关关键词，这会污染账号标签，长期比单条限流更伤。
- 标题党到货不对板会掉粉、掉收藏、拉低完播：缺口再大，点进去必须兑现。
- "爆款"不是承诺结果，本技能只优化"被点开"和"被搜到"这两段可控的部分。

## 接力（标题定稿后往哪走）

标题不是终点，定稿后主动提示用户下一步，并把交接物一起给出去：

| 下一步 | 交给谁 | 交接什么 |
|---|---|---|
| 写正文 | `space-xhs-writer` | 定稿标题 + 押中的 3~5 个搜索词（正文首句和标签要与之呼应） |
| 做封面 | `xhs-html` | 定稿标题**再压缩到 ≤12 字**的封面文案 + 情绪基调 |
| 没选题、不知道写什么 | `space-xhs-positioning`（没定位）或 `space-xhs-hotspot`（有定位缺选题） | 赛道词 |
| 发出去了但没人点 | `space-xhs-note-analytics` | 曝光量 + 点击率——**CTR 低才是标题/封面的锅**，曝光就低说明问题在上游，别乱改标题 |

**一致性硬要求**：核心搜索词必须在 **标题、正文首句、话题标签** 三处同时出现。只在标题里出现，搜索权重会被稀释。
